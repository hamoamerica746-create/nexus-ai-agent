# NEXUS — AI Agent Website

وكيل ذكاء اصطناعي احترافي بواجهة عربية (RTL) متصل بـ **NVIDIA NIM API**، مع موديلين:

| الموديل | النوع | المميزات |
|---|---|---|
| `minimaxai/minimax-m3.1-flash` | نصوص + تفكير | الأسرع، كود، محادثات طويلة |
| `nvidia/nemotron-3.5-super-vl-120b-a12b` | رؤية بصرية + نصوص | تحليل صور، تفكير عميق |

## المميزات

- ⚡ ردود متدفقة (SSE Streaming) لحظية مع مؤشر كتابة
- 🧠 عرض **عملية التفكير** (`reasoning_content`) في لوحة قابلة للطي
- 🖥️ **وضع الوكيل (Agent Mode):** كمبيوتر Linux حقيقي ينفذ الأوامر بنفسه عبر حلقة Agent ذكية
  - الموديل يصدر أوامر bash بصيغة `<tool_call>`، والخادم ينفذها في جلسة ثابتة ويعيد الناتج
  - حتى 6 خطوات تنفيذ لكل مهمة، مع عرض كل أمر ومخرجاته و exit code داخل المحادثة
- ⌨️ **ترمنال يدوي** (`/api/exec`): bash حي بذاكرة جلسة محفوظة (cd، history، تثبيت حزم)
- 👁️ إرفاق وتحليل الصور (موديل Nemotron VL) مع ضغط تلقائي
- 💬 محادثات متعددة تُحفظ محلياً — بحث، إعادة تسمية، حذف
- 📝 Markdown كامل مع تلوين أكواد وزر نسخ لكل بلوك
- 🎛️ إعدادات: Temperature، الحد الأقصى للرموز، System Prompt
- 🛑 إيقاف التوليد، إعادة التوليد، نسخ الردود
- 📱 تجاوب كامل للموبايل (اختُبر على 390px و320px بصفر overflow)
- 🎨 تصميم Dark احترافي: Aurora، Glassmorphism
- 🔒 مفتاح الـ API موجود على الخادم فقط (لا يصل للمتصفح إطلاقاً)

## واجهات الـ API

| المسار | الوظيفة |
|---|---|
| `POST /api/chat` | محادثة عادية ببث SSE |
| `POST /api/agent` | حلقة وكيل ذاتية التنفيذ (أوامر + ردود) |
| `POST /api/exec` | تنفيذ أمر bash مباشر `{command, sessionId}` |
| `GET /api/models` | قائمة الموديلات |
| `GET /api/health` | حالة الخدمة |

مجلد عمل البيئة: `/home/user/agent-workspace` (يُضبط عبر `AGENT_WORKSPACE`).
حدود الأمان: مهلة الأمر 30 ثانية، سقف المخرجات 14k حرف، أقصى 6 خطوات وكيل.

## التشغيل

```bash
npm install
npm start
# ثم افتح: http://localhost:4000
```

## الإعداد

يُضبط المفتاح في ملف `.env`:

```env
NVIDIA_API_KEY=nvapi-...
UPSTREAM_URL=https://integrate.api.nvidia.com/v1/chat/completions
PORT=4000
```

## ملاحظات أمنية

- المفتاح لا يظهر في أي كود من جهة العميل — كل الطلبات تمر عبر `/api/chat`.
- قائمة الموديلات المسموحة محصورة على الخادم (allow-list).
- يُنصح بتدوير المفتاح إذا تمت مشاركته علناً، واستضافة الخادم خلف HTTPS.
